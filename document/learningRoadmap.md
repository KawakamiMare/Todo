#### 達成済み（チェック済み・5/24時点）

- 現Todoの**一覧・追加・削除**（＋更新）がReact+TSで動く
- Spring Boot API と接続してデータの取得・変更ができる

#### 完了条件（5/24改訂・必須）

- `App` → `useTodos` → `todoService` → API の流れを、紙の矢印で説明できる

- 初回取得と「追加・更新・削除後に一覧が変わる」仕組みを説明できる  
  - TanStack Query 利用時: `queryKey` / `queryFn` / `invalidateQueries` の役割  
  - または: `useTodos.ts` のコメントアウトされた `useEffect`+`fetch` 版を一度動かし、Query との違いを比較できる
- `EditModal` の「親が state を持ち、子がコールバックで返す」構造を説明できる
- コンポーネント分割（`TodoForm` / `TodoTable` / `EditModal`）の理由を説明できる

#### 完了条件（推奨・5/24改訂）

- React公式ハンズオンの **Effect（同期）周辺** を実施（別ミニアプリ or 既存コードのコメント版でも可）
